# Lyrics

A WPS can show the lyrics of the track that is playing. Each WPS decides whether it shows them and how. You don't need to do anything while the music plays.

## Where lyrics come from

| Source | Formats |
|---|---|
| A file next to the track with the same name | `Song.lrc` (LRC, synced), then `Song.txt` (plain text) |
| The track's own tags | MP3 (ID3v2 `SYLT`, then `USLT`), FLAC / Ogg Vorbis / Opus (`LYRICS`, `UNSYNCEDLYRICS`, `SYNCEDLYRICS`), M4A / MP4 (`©lyr`) |

**Settings > Playback > Lyrics** has the options:

| Setting | Values |
|---|---|
| Show Lyrics | On (default) / Off |
| Lyrics Source | File First (default): the file wins if both exist. Embedded First: the tags win. |

Supported formats:
- **LRC** (`[mm:ss.xx] line`): several time tags on one line, `[offset:±ms]` and header tags (`[ar:]`, `[ti:]`, …) are all handled.
- **Enhanced LRC** (A2, `<mm:ss.xx>` word times): the word times are dropped and each line is shown as a whole.
- **Plain text:** there are no times, so the view moves through the lyrics at an even pace over the middle 80% of the track.
- **Lyrics stored in tags** can themselves be LRC. Many taggers do this, and those lyrics are shown synced.

Text can be UTF-8 or UTF-16 (with or without a BOM). Any other text is read in the codepage set in **Settings > General > Display > Default Codepage**.

## Languages and fonts

Lyrics use the WPS's own fonts. If a font lacks a character (Japanese, Chinese or Korean in a Latin font, for example), that character comes from the **fallback font** instead: **Theme Settings > Fallback Font**. The default is `16-GNU-Unifont`, which is in the fonts pack and covers the whole Basic Multilingual Plane. You can pick any other `.fnt`, for example a Noto Sans CJK converted with `tools/convttf`. The fallback works for all text, not only lyrics, and characters are aligned on the line's baseline.

Vietnamese and other Latin-script languages need a font that has their characters. The GeistMono faces in the Snappy themes cover them.

## Skin tags

| Tag | What it does |
|---|---|
| `%yl` / `%yl(n)` | The lyric line `n` lines after the one being sung: `0` is the current line, `1` the next, `-1` the previous. Before the first synced line, `%yl(0)` is empty and `%yl(1)` shows the first line. |
| `%?yf<synced\|plain\|none>` | What the track has. A two-branch `%?yf<yes\|no>` works as well. |
| `%yp` | How far through the current line playback is, 0–100. |
| `%yb(x, y, w, h [, inactive [, align [, gap]]])` | A block of lyrics that scrolls with the song. `w`/`h` of `0` mean "to the edge of the viewport". `inactive` is the colour of the lines that aren't being sung (default: a mix of the viewport's foreground and background colours). `align` is `left`, `center` (default) or `right`. `gap` is the space in pixels between lyric lines. |

About `%yb`:
- The line being sung is drawn in the viewport's foreground colour and kept in the middle of the block. The block eases to the next line as it starts.
- Long lines wrap at spaces. CJK text can wrap between any two characters.
- The block **clears its own viewport** on every redraw, so put it in a viewport of its own. `%Vt` works with it, so it can sit on a veil over the cover.
- Its font is the viewport's font.

### Examples

The current line and the next line:

```
%V(30,616,-30,36,3)
%Vt(0)
%al%s%yl(0)
%V(30,652,-30,30,2)
%Vf(8E8C86)
%al%s%yl(1)
```

A full-screen block that shows only when the track has lyrics:

```
%?yf<%Vd(lyr)|%Vd(lyr)|>
%Vl(lyr,30,250,-30,490,3)
%Vt(0)
%yb(0,0,0,0,8E8C86,center,14)
```

A single-line caption: a gap larger than the viewport hides the neighbouring lines.

```
%Vl(cap,32,510,416,52,3)
%Vb(0C0D0E)
%Vt(55)
%yb(0,0,0,0,-,center,80)
```

## Demo themes

Three themes show the tags. All are built on Snappy Animated and generated by `themes/gen_skins.py`:

| Theme | Layout |
|---|---|
| Snappy Lyrics | The whole screen is a lyrics block over the blurred cover, with the title and artist above it. |
| Snappy Lyrics Lines | The line being sung and the next line replace the peak meter band while a track has lyrics. |
| Snappy Lyrics Caption | One line on a veil across the foot of the cover, like a subtitle. |

## For developers

- `apps/lyrics.c` finds, decodes and parses lyrics. It loads them for the playing track the first time a skin asks, and keeps them until the track changes (up to 1500 lines, 96 KiB of text). `lyrics_position()` returns the current line.
- `apps/gui/skin_engine/skin_lyrics.c` draws `%yb`. It redraws only when the line or the scroll position changes.
- The glyph fallback is in `firmware/font.c` (`font_glyph_font()`), and `firmware/drivers/lcd-bitmap-common.c` uses it when drawing. A glyph counts as missing when its code point is outside the font's range, or when it shares the default glyph's bitmap, which is how `convttf` and `convbdf` fill gaps in a font.
